# фичи для банковского приложения

## О проекте
в проекте содержаться функции 
для скрывания номера карты и номера счета 
пользователя (get_mask_card_number и 
get_mask_account) они находятся в модуле src
в файле masks.py

так же проекте содержаться функции 
для преобразования номера счета
и карты и передачи их предыдущим функциям
и также функция преобразования даты 
(mask_account_card и 
get_date) они находятся в модуле src
в файле witget.py

в проекте содержаться функции 
для обработки словарей по ключу
и бля сортировки словарей по дате
(filter_by_state и 
sort_by_date) они находятся в модуле src
в файле processing.py

в проекте содержаться функции 
для обработки списка словарей с банковскими оперциями клиента
для сортировки их по валюте и для обработки описания операций
(filter_by_currency и 
transaction_descriptions) так же есть функция для генерации
номеров банковских карт (card_number_generator)
они все находятся в модуле src
в файле generator.py

эти функции можно протестировать в файле
main.py

### Тесты

тесты всех этих функций находяться в модуле tests в файлах
названых по названиям файлов (test_название файла) (в файле conftest находяться
все фикстуры)
