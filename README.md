# фичи для банковского приложения

## О проекте
в проекте содержаться функции 
для скрывания номера карты и номера счета 
пользователя (get_mask_card_number и 
get_mask_account) они находятся в модуле src
в файле masks.py

так же проекте содержаться функции 
для преобразования номера счета
и карты и передачи их предыдущим функциям
и также функция преобразования даты 
(mask_account_card и 
get_date) они находятся в модуле src
в файле witget.py

в проекте содержаться функции 
для обработки словарей по ключу
и бля сортировки словарей по дате
(filter_by_state и 
sort_by_date) они находятся в модуле src
в файле processing.py

эти функции можно протестировать в файле
main.py
